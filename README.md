📊 Data Jobs Dashboard -- Power BI

An interactive Data Jobs Dashboard built in Microsoft Power BI to
explore job-market trends, salaries, job counts, and data-related job
roles.

This project was created as part of my learning journey using Luke
Barousse's 8-Hour Power BI Course. I used the course as a learning
reference and applied the concepts to build an interactive dashboard
with my own implementation and layout.

🎯 Project Overview

The dashboard provides a high-level view of the data job market and
allows users to compare different job roles based on:

Job count

Median yearly salary

Median hourly salary

Salary rating

Job trends over time

Highest-paying data roles

Job-specific salary comparisons

The report also includes a separate Job Title Drill-Through page,
allowing users to select a specific role and explore more detailed
information about that job.

📌 Dashboard Features

📈 Job Market Analysis

Used line charts to analyse job counts and identify trends over
time.

Compared job volumes across 2024.

Analysed salary differences between data-related job titles.

🗺️ Geospatial Analysis

Used map charts to visualise the global distribution of data
jobs.

🎯 KPI Indicators & Tables

Used Card visuals to highlight key metrics such as:

Total Job Count

Median Yearly Salary

Median Hourly Salary

Salary Rating

Used tables to provide detailed, sortable job-level information.

📊 Salary Analysis

Compared median yearly salary with median hourly salary.

Identified some of the highest-paying roles, including:

Senior Data Scientist

Senior Data Engineer

Data Engineer

Data Scientist

Senior Data Analyst

Data Analyst

🎨 Dashboard Design

Designed a clean and user-friendly dashboard layout.

Used a consistent visual theme to make the report easy to navigate.

Experimented with different Power BI visual types to improve the
overall data story.

🔎 Interactive Reporting

Slicers: Filter the report by Job Title.

Buttons & Bookmarks: Created navigation between report sections.

Drill-Through: Navigate from the high-level dashboard to a
detailed page for a selected job title.

Interactive tables: Explore job counts and salary information by
role.
